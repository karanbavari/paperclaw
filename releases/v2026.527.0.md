# PaperClaw v2026.527.0

PaperClaw v2026.527.0 is the first prepared stable release for the KesarCloud-maintained PaperClaw project after the README, docs, and release packaging refresh.

## Highlights

- Repositioned PaperClaw as a distinct open-source control plane for human-governed AI-agent companies, based on the MIT-licensed Paperclip AI framework/project structure.
- Rewrote the public README around production-oriented automation, quickstart setup, operating model, core capabilities, and sector-specific use cases.
- Removed the old README media embeds so the project now opens with product clarity and install instructions.
- Prepared release packaging for the scoped CLI package `@kesarcloud/paperclaw`, while preserving the installed `paperclaw` binary.
- Aligned release automation and docs around `main` as the canonical branch.

## Product Surface

- Companies, goals, agents, org charts, issues, comments, approvals, budgets, and activity logs.
- Heartbeat execution through local CLI/session adapters, process and HTTP adapters, OpenClaw gateway support, and external adapter plugins.
- Company memory, meeting rooms, Research Lab, marketplace discovery, plugin setup, tool permissions, Outcome Center, and Ops Incident Center.
- Embedded PostgreSQL local mode, Docker support, authenticated/private deployment options, and hosted Postgres deployment paths.

## Release Notes

This release is a fresh baseline for public release preparation. Older release-note files remain in the repository for project history, but this release does not depend on historical git tag backfill.

Before live publishing, maintainers must confirm:

- the working tree is clean,
- `@kesarcloud/*` package ownership and npm trusted publishing are configured,
- the exact source commit passes typecheck, tests, and build,
- the stable workflow dry run succeeds,
- release smoke testing passes.
