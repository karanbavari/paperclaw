# Expensify Tools

Use the PaperClaw Expensify plugin for guarded expense report and reimbursement workflows.

- Keep dry run enabled until a board operator approves live mutations.
- Confirm partner user ID, policy, report export, employee update, and reimbursement job payloads before writes.
- Treat employee updates and reimbursement-related changes as governed finance actions.
- These tools do not provide accounting, tax, investment, or legal advice.
