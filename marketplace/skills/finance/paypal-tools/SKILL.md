# PayPal Tools

Use the PaperClaw PayPal plugin for guarded invoice, order, payment, refund, and payout workflows.

- Keep dry run enabled until a board operator approves live mutations.
- Confirm merchant, invoice, order, capture, refund, and payout payloads before writes.
- Treat refunds and payouts as governed finance actions requiring explicit approval.
- These tools do not provide accounting, tax, investment, or legal advice.
