# NetSuite Tools

Use the PaperClaw NetSuite plugin for guarded ERP finance workflows.

- Keep dry run enabled until a board operator approves live mutations.
- Confirm account-specific REST base URL, record IDs, SuiteQL, and journal payloads before writes.
- Use SuiteQL/read tools before creating invoices, bills, or journal entries.
- These tools do not provide accounting, tax, investment, or legal advice.
