# FreshBooks Tools

Use the PaperClaw FreshBooks plugin for guarded client billing and expense workflows.

- Keep dry run enabled until a board operator approves live mutations.
- Confirm account ID, business ID, client, invoice, expense, payment, and estimate payloads before writes.
- Prefer list/get/report operations for context gathering.
- These tools do not provide accounting, tax, investment, or legal advice.
