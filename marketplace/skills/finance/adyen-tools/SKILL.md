# Adyen Tools

Use the PaperClaw Adyen plugin for guarded payment, refund, payout, transfer, and balance platform workflows.

- Keep dry run enabled until a board operator approves live mutations.
- Confirm merchant account, API environment, amount, currency, PSP reference, and transfer payloads before writes.
- Treat captures, refunds, payouts, and transfers as governed finance actions.
- These tools do not provide accounting, tax, investment, or legal advice.
