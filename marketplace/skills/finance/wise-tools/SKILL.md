# Wise Tools

Use the PaperClaw Wise plugin for guarded balance, FX, recipient, and transfer workflows.

- Keep dry run enabled until a board operator approves live mutations.
- Confirm profile, balance, currency, quote, recipient, and transfer payloads before writes.
- Treat transfer creation as a governed finance action requiring explicit approval.
- These tools do not provide accounting, tax, investment, or legal advice.
