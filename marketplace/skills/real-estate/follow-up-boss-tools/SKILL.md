# Follow Up Boss Real Estate Tools

Use the PaperClaw Follow Up Boss plugin for governed real-estate workflows.

## Scope
- Region: Global/USA
- Capabilities: people, leads, events, tasks, notes
- Official-provider API only; do not scrape portals or bypass provider terms.

## Operating Rules
- Confirm the plugin is connected before using tools.
- Keep dry-run enabled for mutating actions until the Board or an authorized manager approves live changes.
- Verify local licensing, privacy, fair-housing, and data-use rules before publishing or acting on property data.
- Prefer specific read tools before enabling raw API access.

## Handoff
After each operation, summarize the provider used, records touched, dry-run/live mode, and any follow-up needed.
