# PaperClaw CLI

The PaperClaw CLI installs, configures, and runs the PaperClaw control plane.

Install with `npx`:

```sh
npx @kesarcloud/paperclaw onboard --yes
npx @kesarcloud/paperclaw run
```

The published package is `@kesarcloud/paperclaw`. It installs a `paperclaw` binary.

For the full project README, see the repository root: [README.md](../README.md).
